================================================================================
                              FOR STUDENTS
================================================================================

Before Exam:
  1. Read: EXAM_STUDENT_GUIDE.md (10 min read)
  2. Check: Internet connection works
  3. Pick: Quiet place without distractions
  4. Prepare: Have name and email ready

During Exam:
  ✓ Click the exam link your instructor sent
  ✓ Enter your full name and email
  ✓ Click "Start Exam"
  ✓ Answer questions (Previous/Next to navigate)
  ✓ Watch timer at top right
  ✓ Click "Submit Exam" when done

If Problem:
  → Read: EXAM_SUBMISSION_TROUBLESHOOTING.md (Student section)
  → Try: Basic fixes (WiFi, browser, email format)
  → Contact: Your instructor with error message

Quick Troubleshooting Table:
  No internet       → Check WiFi, restart router, wait 1 min
  Invalid email     → Fix format to: name@domain.com
  Submission failed → System retries 3 times, wait for it
  Browser frozen    → Close completely, reopen, retry
  Time ran out      → Exam auto-submits, check results

================================================================================
                              FOR INSTRUCTORS
================================================================================

Before Exam:
  1. Read: EXAM_ADMIN_CHECKLIST.md
  2. 48 hours before: Database & content verification
  3. 24 hours before: Student communication & system check
  4. 1 hour before: Final system test, setup monitoring
  5. Send: EXAM_STUDENT_GUIDE.md to students

During Exam:
  1. Open: /admin/exams/[exam-id] monitoring dashboard
  2. Enable: Auto-refresh (every 5 seconds)
  3. Watch: Total submissions, average score, pass rate
  4. Monitor: Every 10-15 minutes for anomalies

Student Has Issues:
  1. Check: /admin/exams/[exam-id] dashboard first
  2. If appears in table: Submission successful!
  3. If NOT in table: Read EXAM_SUBMISSION_TROUBLESHOOTING.md
  4. Help: Follow quick fixes for their error
  5. Escalate: If all fixes fail, contact technical support

Common Issues & Fixes:
  No submissions      → Verify exam is published, link shared
  All students failing→ Check database/server status
  One student failing → Check their email format, have them retry
  Submission slow     → Normal, wait; don't panic students
  Error messages      → See EXAM_SUBMISSION_TROUBLESHOOTING.md

Support Hierarchy:
  Level 1: Student reads guides, tries basic fixes (5 min)
  Level 2: Instructor checks dashboard, helps with troubleshooting (10 min)
  Level 3: Technical support if Level 2 fails (escalation)

================================================================================
                              SUCCESS METRICS
================================================================================

Exam Went Well If:
  ✓ 95%+ of students submitted successfully
  ✓ Pass rate is 60-80%
  ✓ Average score is 60-80%
  ✓ No bulk error messages
  ✓ Monitoring dashboard shows all submissions
  ✓ Students report successful submission
  ✓ Completion time is reasonable (30-120 min)

Watch Out For:
  ⚠ Zero submissions after 10 minutes
  ⚠ Average score <40% or >90%
  ⚠ Pass rate <40% (exam too hard)
  ⚠ Pass rate >95% (exam too easy)
  ⚠ Error messages appearing repeatedly
  ⚠ Slow submission responses
